# Рабочая папка для игры на QSP

Эта папка — место, где вы пишете текстовую игру на [QSP](https://qsp.org). После однократной установки в ней есть всё нужное:

- **редактор** — программа для работы с текстом. Здесь это VSCodium, свободная версия Visual Studio Code;
- **расширение QSP** — дополнение к редактору, которое понимает язык QSP: раскрашивает код, подчёркивает ошибки и показывает список локаций;
- **плеер** — программа, в которой играют в игры на QSP;
- **ваша игра**. Для начала там лежит маленький пример: его можно переделать или удалить.

Всё хранится внутри этой папки. Права администратора не нужны, остальной компьютер установка не трогает.

## Что понадобится

- Windows 10 или 11, macOS или 64-битный Linux на процессоре Intel или AMD.
- Около 2 ГБ свободного места на диске.
- Интернет на время установки: она скачивает примерно 450 МБ.

## Быстрый старт

> Проверено на Linux. Шаги для Windows и macOS на настоящих компьютерах ещё не проверены.

1. **Скачайте архив:** [qsp-game-template.zip](https://github.com/QSPFoundation/qsp-game-template/releases/latest/download/qsp-game-template.zip).
   ZIP-файл — это архив, то есть несколько файлов, упакованных в один.
   *Получилось, если* файл `qsp-game-template.zip` появился в папке «Загрузки».

2. **Распакуйте архив.** Windows: щёлкните файл правой кнопкой мыши → **Извлечь все…** → **Извлечь**. macOS: дважды щёлкните файл. Linux: правая кнопка → **Извлечь сюда**.
   Внутри появится папка `qsp-game`. Перенесите её мышью туда, где храните свои документы.
   *Получилось, если* в папке `qsp-game` лежат файлы вроде `install-windows.cmd` и папка `game`.

3. **Запустите установку** для своей системы:
   - **Windows:** дважды щёлкните `install-windows.cmd`. Если появится синее окно «Система Windows защитила ваш компьютер», нажмите **Подробнее** → **Выполнить в любом случае**.
   - **macOS:** дважды щёлкните `install-macos.command`. Если macOS скажет, что не может открыть файл, щёлкните его с зажатой клавишей **Control**, выберите **Открыть**, а затем ещё раз **Открыть**.
   - **Linux:** терминал — это окно, в котором набирают команды. Щёлкните правой кнопкой по пустому месту в папке `qsp-game`, выберите **Открыть в терминале**, наберите строку ниже и нажмите **Enter**:
     ```
     bash install-linux.sh
     ```
     Если пункта **Открыть в терминале** нет, запустите программу «Терминал», наберите `cd` и пробел, перетащите папку `qsp-game` мышью в окно терминала, нажмите **Enter**, а затем наберите строку выше.

   Откроется окно с текстом и спросит язык: наберите `1` для русского и нажмите **Enter**. Установка займёт несколько минут.
   *Получилось, если* появилась строка, которая начинается со слова `Готово!`. Нажмите **Enter**, чтобы завершить установку.

4. **Откройте игру:** дважды щёлкните `open-game-windows.cmd` (Windows) или `open-game-macos.command` (macOS). В Linux наберите в терминале:
   ```
   bash open-game-linux.sh
   ```
   *Получилось, если* открылся редактор: слева файл `main.qsps`, а под списком файлов раздел **QSP LOCATIONS** со списком локаций игры.

5. **Сыграйте:** нажмите **F5** или кнопку **▷** вверху справа над открытым файлом. На ноутбуке для F5 иногда нужно держать клавишу **Fn**.
   *Получилось, если* открылся плеер QSP с текстом «Вы стоите в тёмной прихожей…». Закройте плеер, чтобы вернуться к тексту.

## Как писать игру

- Щёлкните `main.qsps` слева, чтобы открыть его. Игра состоит из **локаций** — мест или сцен. Локация начинается строкой `# название` и заканчивается строкой `---`. Строки, которые начинаются с `!`, — заметки для вас, игрок их не видит.
- Редактор сам сохраняет текст через секунду после того, как вы перестали печатать.
- Красная волнистая линия отмечает ошибку. Наведите на неё мышь, чтобы прочитать, в чём дело.
- Игру можно разделить на несколько файлов: правая кнопка по списку файлов → **Создать файл…**, имя должно заканчиваться на `.qsps`. В игру попадут все такие файлы, а начнётся она с первой локации файла `main.qsps`.
- Картинки кладите в папку `game/images`, звуки — в `game/sounds`.
- **Ctrl+K**, затем **J** в открытом файле игры — схема: какая локация куда ведёт.
- Чтобы вернуть прежний вариант файла, откройте раздел **Временная шкала** внизу списка файлов и щёлкните нужный момент.

## Как отдать игру игрокам

Каждое нажатие **F5** собирает файл `game/game.qsp` — это и есть игра. Отдайте игрокам `game.qsp` вместе с папками `images` и `sounds`, например одним ZIP-архивом. Игроки открывают `game.qsp` в плеере QSP с сайта [qsp.org](https://qsp.org).

## Как проверить игру в qSpider

qSpider — второй плеер, он показывает HTML так же, как браузер. Он тоже установлен. Сначала нажмите **F5**, затем выберите меню **Терминал** → **Запуск задачи…** → **Open in qSpider**. *(Пока не проверено.)* В qSpider имена картинок и звуков должны совпадать вплоть до заглавных букв: `Image.jpg` и `image.jpg` для него разные файлы.

## ИИ-помощник

С игрой может помогать ИИ-помощник, например Claude или Cursor. Расширение QSP даёт ему те же знания об игре, что и редактору: список локаций, где какая из них используется, найденные ошибки. Для этого есть MCP — общий способ подключать программы к ИИ-помощникам.

1. Откройте игру (шаг 4).
2. Нажмите **Ctrl+Shift+P** (в macOS — **Cmd+Shift+P**), наберите `Copy MCP Server Config` и нажмите **Enter**. Редактор скопирует текст настроек.
3. Вставьте этот текст в настройки MCP помощника. Где они находятся, написано в справке самого помощника.

После каждого обновления (повторного шага 3) скопируйте настройки заново: в них записана версия расширения. Помощник читает текст вашей игры — учтите это, если игра не для чужих глаз. *(Проверено, что сервер отвечает на вопросы о стартовой игре. Подключение конкретных помощников пока не проверено.)*

## Что лежит в папке

| Папка или файл | Что это |
|---|---|
| `game` | Ваша игра. Для резервной копии копируйте именно её. |
| `tools` | Редактор и плееры. Её можно удалить: установка создаст её заново. |
| `setup` | Файлы для установки. Их лучше не трогать. |
| `install-…`, `open-game-…` | Файлы, которыми запускают установку и редактор. |

## Обновление

Запустите установку ещё раз (шаг 3). Она обновит редактор, расширение и плееры, а игру и настройки редактора оставит как есть.

## Если что-то пошло не так

- **Установка остановилась с ошибкой.** В сообщении написано, что случилось. Проверьте интернет и запустите установку снова. Всё, что она делала, записано в файл `tools/setup.log`.
- **F5 пишет, что не может запустить плеер.** Запустите установку ещё раз: она вернёт недостающее.
- **В Linux не открывается плеер.** Ему нужна библиотека GTK 3. Она есть в Ubuntu, Linux Mint и Fedora.
- **После переноса папки редактор выглядит как новый** (macOS и некоторые версии Linux). Там редактор хранит настройки вне папки и связывает их с её местом на диске. Игра при этом не меняется.
- **Есть старая игра в файле `.qsp`.** Нажмите **Ctrl+Shift+P** (в macOS — **Cmd+Shift+P**), наберите `Import QSP Game`, нажмите **Enter** и выберите файл: редактор превратит игру обратно в текст. Игры для QSP 5.7 иногда нужно поправить под нынешние плееры, об этом [статья Aleks Versus](https://aleksversus.github.io/howdo_faq/docs/articles/transition_570_590).

## Где учить QSP

- [Вики QSP](https://wiki.qsp.org) — полное описание языка.
- [Справочник «Как сделать?» от Aleks Versus](https://aleksversus.github.io/howdo_faq/) — ответы на частые вопросы, под нынешние плееры.
- [Форум QSP](https://qsp.org) — сообщество авторов.
- Совет, которому следуют многие авторы: сначала напишите весь сюжет, а сложные места замените заглушками («Победить в бою», «Проиграть в бою»); потом сложный код и только в конце картинки и музыку. Так игра чаще доходит до конца.
